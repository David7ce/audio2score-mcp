# audio2score-mcp Stage 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two chained CLI scripts that turn an audio file into a MusicXML score: `transcribe.py` (audio → MIDI via basic-pitch) and `to_score.py` (MIDI → MusicXML via music21).

**Architecture:** Two independent, single-purpose scripts with no shared module, no server, no daemon. Each takes one file path argument, writes one output file next to the input, and exits. They are chained manually by running one after the other — the pause between them is intentional (see spec).

**Tech Stack:** Python (3.12, see constraint below), `basic-pitch` (audio→MIDI), `music21` (MIDI→MusicXML), `uv` for venv/dependency management (already installed on this machine at `/c/Users/d7/.local/bin/uv`).

**Spec:** `docs/superpowers/specs/2026-08-20-audio2score-design.md`

## Global Constraints

- **Python 3.12, not 3.13.** `basic-pitch` (PyPI, checked 2026-08-20) declares support only through Python 3.11 and has no `requires_python` floor, so pip won't block a newer interpreter — but this machine's default `python` on PATH is 3.13, which is untested by basic-pitch's own dependency (onnxruntime) and risks missing wheels. A `uv`-managed Python 3.12.13 is already present on this machine (`py -0p` confirmed it), which is the closer, safer match. Use it for this project's venv.
- **No MCP server.** Plain CLI scripts only, run manually. (Spec Non-goals.)
- **No automated test suite.** Both scripts are thin wrappers around external libraries with no business logic of their own to unit-test; verification is a real run against real audio, per spec's Testing section. Each task's "test" steps below are real invocations against real files, not pytest.
- **Outputs are written next to the input file**, same directory, same base filename, different extension. No output-folder config, no CLI flag for it.
- **Fail loudly, no silent fallback.** Missing input file or a library failure must print a clear error to stderr and exit non-zero — never swallow the error and produce a partial or empty output file.
- **basic-pitch's `predict_and_save` writes `<stem>_basic_pitch.mid`, not `<stem>.mid`** — `transcribe.py` must rename the file after generation to match the spec's "same base filename" convention.

### Task 2: `transcribe.py` — audio to MIDI

**Files:**
- Create: `transcribe.py`

**Interfaces:**
- Consumes: `venv/Scripts/python.exe` with `basic_pitch` installed (Task 1).
- Produces: a `transcribe(audio_path: pathlib.Path) -> pathlib.Path` function, and a CLI entry point `python transcribe.py <audio_path>`. Task 3 does not import this file directly — the two scripts are chained by running MIDI's output path as Task 3's input, not by Python import.

- [ ] **Step 1: Write `transcribe.py`**

```python
#!/usr/bin/env python3
"""Transcribe an audio file to MIDI using basic-pitch."""
import argparse
import pathlib
import sys

from basic_pitch.inference import predict_and_save
from basic_pitch import ICASSP_2022_MODEL_PATH


def transcribe(audio_path: pathlib.Path) -> pathlib.Path:
    """Run basic-pitch on audio_path, return the path to the written .mid file."""
    if not audio_path.is_file():
        raise FileNotFoundError(f"Audio file not found: {audio_path}")

    output_dir = audio_path.parent
    predict_and_save(
        [str(audio_path)],
        str(output_dir),
        save_midi=True,
        sonify_midi=False,
        save_model_outputs=False,
        save_notes=False,
        model_path=ICASSP_2022_MODEL_PATH,
    )

    # predict_and_save always names its output "<stem>_basic_pitch.mid" -
    # rename to match this project's "same base filename" convention.
    generated = output_dir / f"{audio_path.stem}_basic_pitch.mid"
    target = output_dir / f"{audio_path.stem}.mid"
    if not generated.is_file():
        raise RuntimeError(f"basic-pitch did not produce expected output: {generated}")
    generated.replace(target)
    return target


def main() -> None:
    parser = argparse.ArgumentParser(description="Transcribe an audio file to MIDI.")
    parser.add_argument("audio_path", type=pathlib.Path, help="Path to the input audio file")
    args = parser.parse_args()

    try:
        output_path = transcribe(args.audio_path)
    except (FileNotFoundError, RuntimeError) as e:
        print(f"Error: {e}", file=sys.stderr)
        sys.exit(1)

    print(f"Wrote {output_path}")


if __name__ == "__main__":
    main()
```

### Task 3: `to_score.py` — MIDI to MusicXML

**Files:**
- Create: `to_score.py`

**Interfaces:**
- Consumes: `venv/Scripts/python.exe` with `music21` installed (Task 1); the `.mid` file produced by Task 2 as its real-run input.
- Produces: a `to_score(midi_path: pathlib.Path) -> pathlib.Path` function, and a CLI entry point `python to_score.py <midi_path>`. This is the last task in Stage 1 — nothing downstream consumes its output within this plan.

- [ ] **Step 1: Write `to_score.py`**

```python
#!/usr/bin/env python3
"""Convert a MIDI file to MusicXML using music21."""
import argparse
import pathlib
import sys

from music21 import converter


def to_score(midi_path: pathlib.Path) -> pathlib.Path:
    """Parse midi_path with music21 and write it out as MusicXML, return the output path."""
    if not midi_path.is_file():
        raise FileNotFoundError(f"MIDI file not found: {midi_path}")

    try:
        score = converter.parse(str(midi_path))
    except Exception as e:
        raise RuntimeError(f"music21 failed to parse {midi_path}: {e}") from e

    target = midi_path.with_suffix(".musicxml")
    score.write("musicxml", fp=str(target))
    return target


def main() -> None:
    parser = argparse.ArgumentParser(description="Convert a MIDI file to MusicXML.")
    parser.add_argument("midi_path", type=pathlib.Path, help="Path to the input MIDI file")
    args = parser.parse_args()

    try:
        output_path = to_score(args.midi_path)
    except (FileNotFoundError, RuntimeError) as e:
        print(f"Error: {e}", file=sys.stderr)
        sys.exit(1)

    print(f"Wrote {output_path}")


if __name__ == "__main__":
    main()
```
